# Smart Widget 工具百宝箱

Windows 桌面版，保留 Open Tools 的主页、日历、时区转换与世界时间、计算换算、图片工具以及文档与文件工具。新增人民币汇率换算、PDF 文字格式刷和使用已知密码另存 PDF 的功能。

- [下载安装包](https://github.com/dodo-Zzz/smart-widget-desktop/releases/latest)，在 Assets 中选择 `*-setup.exe`。
- 已安装的版本可用应用顶部的检查更新按钮获取新版本。
- [源码分支](https://github.com/dodo-Zzz/smart-widget-desktop/tree/desktop) · [发版和签名说明](docs/SMART-WIDGET-RELEASE.md)
- [Open Tools 上游项目](https://github.com/Bulua/open-tools) · [许可证](LICENSE)

## 从源码运行

使用 Node.js 22，在仓库目录运行 `npm ci` 和 `npm run dev`，然后打开终端显示的本地地址。Windows 专用功能通过桌面安装版提供。
